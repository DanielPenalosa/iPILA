# Sound Assets

Place notification sound files here.

## Required File:
- `notification.mp3` - A lively, longer notification sound (5-10 seconds) that plays in loop when:
  - Admin receives a new report
  - Barangay user is assigned a report
  - Department user is assigned a report

## Requirements:
- **Duration**: 5-10 seconds (longer and more noticeable)
- **Style**: Lively, attention-grabbing bell or chime sound
- **File size**: Keep under 500KB
- **Format**: MP3 for cross-platform compatibility
- **Loop-friendly**: Should sound natural when repeated

## Recommendations:
- Alarm-style sounds work well (not too harsh)
- Phone ringtone style notifications
- Multiple bell chimes
- Pleasant but urgent-sounding

## Free Sound Resources:
- https://pixabay.com/sound-effects/ (search: "notification long" or "alarm bell")
- https://freesound.org/ (search: "notification loop")
- https://mixkit.co/free-sound-effects/ (Notification section)
- https://soundbible.com/ (Alerts & Alarms)

## How to Replace:
1. Download a notification sound from above resources
2. Convert to MP3 if needed (use https://cloudconvert.com/wav-to-mp3)
3. Rename to `notification.mp3`
4. Replace the existing file in this directory

The sound will loop continuously until the user clicks the popup notification or dismisses it.
