# Sound Assets

Place notification sound files here.

## Required File:
- `notification.mp3` - A bell or notification sound that plays when:
  - Admin receives a new report
  - Barangay user is assigned a report
  - Department user is assigned a report

## Recommendations:
- Use a short sound (1-2 seconds)
- Keep file size small (< 100KB)
- Use MP3 format for cross-platform compatibility
- Suggested sounds: bell, chime, or gentle notification tone

## Free Sound Resources:
- https://pixabay.com/sound-effects/
- https://freesound.org/
- https://mixkit.co/free-sound-effects/

Download a notification sound and rename it to `notification.mp3`, then place it in this directory.
